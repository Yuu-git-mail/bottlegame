面1 残り0 置き場0/5

遊び方

  • 木の板が何枚も重なり、色のネジで留めてある。
  • ネジをタップすると外れる。ただし上に別の板がかぶっているネジは外せない。
  • 外したネジは、上の同じ色の箱へ飛ぶ。箱は 3 本で満ちると去り、次の色の箱が来る。
  • 合う箱が無いネジは置き場(5 マス)へ。合う色の箱が来ると自動で移る。
  • 板はネジが全部外れると落ちる。全部のネジを外したらクリア。
  • 置き場がいっぱいで外せるネジが無くなると「手がありません」。戻すは何回でも使える。
  • どの面も、置き場を 3 マスまでしか使わない解き方がある。

操作

  • スマホ: ネジをタップ。下のボタンで戻す・ヒント・やり直し・面一覧。
  • PC: クリック、または ← → で外せるネジを選んで Space。Z = 戻す、H = ヒント、R = やり直し、L = 面一覧。
