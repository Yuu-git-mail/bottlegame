# 磁石つなぎ（games/magnet）

本人の案「磁石のパズルゲーム。S と N をカチカチと合わせていく」（2026-10-14）。

ゴール: 全部の磁石の端が N–S で吸い付いたらクリア。磁石は 1 本以上の鎖か輪になる。
理由: 「カチカチ合わせる」手触りを 1 手ごとに返せて、勝ち条件が盤を見れば分かる。

- 磁石の形: 片端（丸い頭）、直線、L 字。赤 = N、青 = S。タップで右に 90 度。
- 面の作り: 盤の全マスを通る輪を作り（半分の格子の全域木の外周）、輪のまま使うか、切って鎖にする。道の向きに 入る端 = S、出る端 = N を付け、固定以外を回して崩す。
- 難しさ: 盤 3×1 → 6×8、鎖の本数、輪、固定タイル。1〜4 面は手で決めた並び。
- 確認: `node games/magnet/check.mjs` で 40 面すべて解けること・答えの数（いまは全面 1 通り）を出す。
- 目安の手数 = 崩したときの回転数。以内なら星 3。

監督用フック window.__dbg
- state(): 面・盤の大きさ・手数・目安・解けたか・吸い付いた端の数・各マスの回転
- cmd('level', n) / cmd('tap', 行, 列) / cmd('solve')（答えへ 1 手進める）/ cmd('reset') / cmd('mute', true|false)
