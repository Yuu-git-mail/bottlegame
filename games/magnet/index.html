面1 手数0 目安0 つながり0

遊び方

  • 盤の磁石をタップすると右に 90 度まわる。
  • 赤が N、青が S。となりの磁石と N と S が向き合うと「カチッ」と吸い付いて光る。
  • N と N、S と S が向き合うと反発してふるえる。何もない所を向いた端もだめ。
  • 全部の磁石の端が吸い付いたらクリア。磁石は鎖か輪になる。
  • 灰色の枠の磁石は固定で、まわせない（正しい向きの手がかり）。
  • 目安の手数以内なら星 3 つ。

操作

  • スマホ: 磁石をタップ。下のボタンで戻す・ヒント・やり直し・面一覧。
  • PC: クリック、または矢印キーで選んで Space。Z = 戻す、H = ヒント、R = やり直し、L = 面一覧。
