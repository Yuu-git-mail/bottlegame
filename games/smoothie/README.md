# スムージーを作れ（games/smoothie）

~/projects/game/smoothie（Android の APK、0.2.0）の web/index.html を写し、傾きセンサーと振りを外して指だけで遊べるようにした版（2026-11-19）。
材料・組み合わせ表（101 種）・判定・図鑑・絵・音は元のまま。表を変えたら元のリポジトリの tools/combo-check.mjs で確かめてから写す。

- 集める（2026-11-19 夜に変更）: アーティファクト「スムージー予定」と同じ仮想スティック。指を置いた所からのずれを傾きとみなし（U×0.15 で 5、遊び 0.35・上限 7）、加速 U×0.2×設定の「転がる速さ」、減速 exp(-0.9t)、最高 U×1.6/秒、壁で 0.45 倍に跳ね返る。指より遅れてついてくる。速さ 0.9 U/秒以上で拾うと「いきおい」+4（U = min(幅, 高さ×0.62)）
- 氷: 傾きで滑る代わりに、0.8 U/秒より遅く当たると「つるっ」と押し出される。勢いよく当てると入る
- 混ぜる: こすった道のり（400 CSS px を 1 単位）× rubGauge 7 × (1 + min(1, 速さ/3))。毎秒 5 単位を超えてこすり続けるとフタがゆるみ、飛ぶとゲージ −15・材料が 1 つ飛ぶ。タップの連打（元の「まぜる！」と同じ計算）とスペースキーでも混ざる
- 外したもの: Android の Tilt・DeviceMotion・水平合わせ・振りの設定と注意書き・戻るキー。confirm は「もう一度押すと消える」に
- ゲーム集の上のバー（← 一覧 / ? / ↻）を付けた。↻ は新しい一杯を最初から。保存は localStorage の smoothie.*（APK とは別）
