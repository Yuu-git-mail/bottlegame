# 寿司リズム（games/sushi）

本人の案（2026-10-14、以前に作ったことがあるもの。データは残っていない）を、メモだけから作り直した版。

- 本編: 右の大将がネタを投げ、まな板の上の輪に来た瞬間にタップ → まな板を叩いてシャリが飛び上がり空中で合体。輪が縮んで重なるのが叩きどき。
- 判定: 粋（±50ms）・よし（±120ms）・おっと（見逃し）。窓の値は依頼文の既定値（Web では調べていない）。
- 注文: 吹き出しのネタだけ合わせる。ちがうネタ −30、ガリ −50、お茶が通る間に叩くと −150、ワサビ付きを挟むと +100。コンボで倍率（最大 2 倍）。
- 盛り付け: 皿 2 貫 +200 / 下駄 6 貫 +800 / パック 8 貫 +1000 で「ヘイお待ち！」。スーパーは 8 小節を過ぎると半額シールで盛り付け点が半分。
- モード: 回転寿司（BPM 96、注文のネタだけ）、スーパーの寿司（112、盛り合わせ 4 種×2、お茶あり）、回らない寿司（132、8 分音符、ちがうネタ・ワサビ・お茶が多い）。
- OP: 日の出・富士・北斎風の波・鳥居・桜吹雪・太鼓「どんつく どんつく」・題字。タップで飛ばせる。初回だけ自動で流れ、お店えらびの「OP をもう一度」で再生。
- 仕込み（ロード中のミニゲーム）: 魚を下ろす（音に合わせて 8 回）と酢飯を仰ぐ（毎秒 5〜9 回の連打を保つ）を交互に。しくじるとたんぽぽを乗せる係。お店えらびで切れる。
- 音: Web Audio で太鼓・拍子木・三味線風（都節音階）を合成。掛け声の声は speechSynthesis（ある端末だけ。切れる）。
- 絵: ピクセルは 160×200 の裏の canvas に描いて 2 倍に拡大。小物は SPRITES の文字列（1 文字 = 1 ピクセル）、人物と背景は四角の組み合わせ。

監督用フック window.__dbg
- state(): 場面・モード・拍・曲の時刻・点・コンボ・直近の判定・注文・飛んでいる物・集計・ミニゲーム
- cmd('start', 'kaiten'|'super'|'mawaranai') / cmd('hit') / cmd('skipOp') / cmd('mute', true|false) / cmd('auto', true|false)（注文のネタを完璧に叩く）/ cmd('minigame', 'fish'|'fan'|'tanpopo') / cmd('step', コマ数)（1/60 秒ずつ進める。試験用）
