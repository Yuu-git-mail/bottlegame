面1 人数0 拠点0 スコア0

遊び方

  • 部隊は自動で前へ進み、自動で撃つ。左右に動かすだけ。
  • 道のゲートを通ると人数が変わる（+N / ×2 / −N）。樽は撃つほど数字が増える。
  • 武器箱を拾うと一定時間、連射・貫通・散弾になる。
  • 敵が部隊に触れると人数が減る。部隊をすり抜けた敵は拠点を削る。
  • 人数 0 か拠点 0 で失敗。最後のボスを倒せば面クリア。
  • クリアするたび 3 つから強化を 1 つ選ぶ。強化はずっと残る。

操作

  • スマホ: 盤面を指で左右になぞる、または下の ◀ ▶
  • PC: ← → または A D、P で一時停止
