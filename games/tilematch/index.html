面1 残り0 枠0/7

遊び方

  • 牌が何段か重なっている。上の牌に少しでもかかっている牌は暗く、まだ取れない。
  • 明るい牌をタップすると、下の 7 つの枠へ入る。
  • 枠の中で同じ絵が 3 つそろうと消える。
  • 枠が 7 つ埋まって消せなくなったら失敗。戻すで何手でも戻せる。
  • 牌を全部消せばクリア。戻す・ヒントを使わなければ星 3 つ。
  • どの面も、取る順番しだいで必ず全部消せるように作ってある。

操作

  • スマホ: 牌をタップ。下のボタンで戻す・ヒント・やり直し・面一覧。
  • PC: クリック、または ← → で取れる牌を選んで Space。Z = 戻す、H = ヒント、R = やり直し、L = 面一覧。
