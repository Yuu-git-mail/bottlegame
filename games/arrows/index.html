遊び方

  • 矢印の線をタップすると、先端の向きへまっすぐ滑って盤の外へ抜ける。
  • 進む先に他の線があると抜けられず、ぶつかって戻る（ミス 1、ハートが 1 つ減る）。
  • 全部の線を抜いたらクリア。どの面も必ず全部抜ける。
  • ハートが 0 で失敗。「♥ なし」にすればミスを数えるだけで終わらない。
  • 全 60 面。6×6 の小さな盤から 20×20 の大きな盤まで。クリアした面には ✓ が付く。

操作

  • スマホ: 線をタップ。下のボタンで「戻す」「ヒント」「面一覧」。
  • PC: クリック。Z = 戻す、H = ヒント、L = 面一覧。
  • ↻ でその面をやり直し。
