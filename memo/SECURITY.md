# メモ（memo/）の守り

このページは、iPhone などのブラウザの中だけで使う一時的なメモ帳です。
書いた内容はその端末のブラウザの保存領域（localStorage、キー `memo_v1`）にだけ置き、どこにも送りません。

## 書いた内容が外へ出ない仕組み

1. 送る処理がない
   本文を扱うのは `localStorage.getItem` / `setItem` だけ。fetch・XHR・WebSocket・sendBeacon・フォーム送信はコードにない。
   外部のスクリプト・フォント・画像・解析・広告も読み込まない。ページの中身は index.html 1 枚で完結している。
2. 仮に何かが紛れ込んでも、ブラウザが外への通信を止める（CSP）
   `default-src 'none'` と `connect-src 'none'` で、ページからの通信と外部の読み込みを全部禁止している。
   スクリプトとスタイルはハッシュ（sha256）で 1 つずつ許可しているので、HTML に別のスクリプトを差し込まれても動かない。
   `require-trusted-types-for 'script'` で innerHTML などの文字列から HTML を作る経路も閉じている（対応ブラウザのみ）。
   `referrer` は送らない。
3. 書いた文字を HTML として扱わない
   表示は `textContent` だけ。行の書き直しは文字だけを受け付ける（`plaintext-only`、貼り付けも文字に直す）。
   保存の中身は読み込むときに形を確かめ、合わないものは捨てる。
4. 他のサイトの枠（iframe）に入れられたら動かない
   枠の中で開かれると、画面を空にしてメモを読み込まない。
5. Service Worker（sw.js）はオフライン起動の控えだけ
   このアプリ自身の 5 ファイル（HTML・manifest・アイコン 2 つ）だけを同じサイトから取って控える。
   それ以外の通信には関わらず、メモの本文も扱わない。

## 確かめた結果（2026-10-26）

- 公開ページで文字を書き、リストへ入れ、開き直し、全部コピーまでの通信を記録した。
  書いている間の通信は 0 件。開き直しで出たのは同じサイトのアプリのファイルの GET だけで、書いた文字を含む通信はなかった。
- 悪いコードが動いた場合を想定し、ページ内から fetch・sendBeacon・WebSocket・外部画像・innerHTML を試した。全部 CSP と Trusted Types で止まり、外へ出た通信はなかった。
- 保存領域に `<img src=… onerror=…>` を入れても、文字として表示されるだけで画像も読み込みも起きなかった。
- iframe に入れると中身が空になった。

確認は PC の Chrome（iPhone の画面幅をまねたもの）で行った。iPhone の Safari 実機での通信計測はまだ。

## 残る弱点（正直に）

- 配っている場所が書き換えられたら守れない
  ページは GitHub Pages から配っている。GitHub アカウントやリポジトリを乗っ取られて index.html と sw.js を書き換えられると、
  CSP ごと消され、次に開いたときに中身を読むコードが届く。Web のページである以上、これはページの側では防げない。
  守りは配る側（アカウントの二段階認証・パスキー、鍵の管理、main の保護）にかかっている。
- 同じサイトの他のページと保存領域を共有している
  `yuu-git-mail.github.io` の下のページはすべて同じ保存領域を見る。今あるページに外部スクリプトはないが、
  将来どれかに広告や解析を入れると、Safari で開いたメモを読まれ得る。
  ホーム画面に追加して使う分は、iOS では Safari と保存領域が分かれる。
- 端末側で消えることがある
  Safari の履歴とWebサイトデータを消すと消える。Safari のまま 7 日ほど開かないと消されることがある（ホーム画面から開く分は対象外）。
- 「全部コピー」を押すとクリップボードに入る。Apple 製品間のユニバーサルクリップボードが有効なら、同じ Apple アカウントの他の端末へ渡る。押さなければ起きない。

## 直すとき

`<script>` か `<style>` の中身を変えたら、`python3 scripts/memo_csp.py` で CSP のハッシュを書き直す。
`--check` でずれていないか確かめられる。忘れるとブラウザがスクリプトを止めてページが動かなくなる。
